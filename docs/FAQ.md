# 자주 묻는 질문 (한국어) — 12문항
> English: [FAQ_EN.md](FAQ_EN.md)

**1. 내 데이터가 외부로 나가나요?**
아니요. 스캔 중 네트워크 전송이 0입니다. 믿지 않으셔도 됩니다 — 코드가 공개돼 있으니 직접 확인하세요: 소스에 네트워크 호출(socket/urllib/requests)이 스캔 경로에 없습니다. 이것이 이 도구의 존재 이유입니다.

**2. 비밀번호나 키 값을 읽어가나요?**
비밀의 **값은 기록하지 않습니다**. "어디에 위험이 있는지(위치·건수)"만 알려드립니다.

**3. '경고모드'(지켜보는 중)가 뭔가요?**
이상을 **알려드리기만** 하고 자동으로 막지는 않는 상태입니다. 자동 조치가 없는데 있는 것처럼 보이게 하지 않습니다 — 저희 원칙입니다.

**4. 탐지 0건이면 안전하다는 뜻인가요?**
아니요. "저희가 점검하는 범위에서 발견된 것이 없다"는 뜻입니다. 공개되기 전의 취약점(제로데이)이나 알려진 패턴 밖의 비밀은 놓칠 수 있습니다.

**5. 이 도구가 뭔가를 고치거나 바꾸나요?**
아니요. 읽기 전용입니다. 설정 변경·파일 수정·차단을 하지 않습니다. 고치는 방법을 알려드리고, 실행은 사용자가 합니다.

**6. 백신(안티바이러스)을 대체하나요?**
아니요. 악성코드 검사 도구가 아니라 **설정·노출 자가진단** 도구입니다. 백신과 함께 쓰세요.

**7. 오탐(잘못된 경고) 같은데 어떻게 신고하나요?**
`ai-hacking-defense feedback` → 유형 2(오탐). 전송될 내용 전문을 먼저 보여드리고, 제출은 GitHub 페이지에서 직접 누르십니다. 오탐 신고는 다음 버전 판정 로직에 바로 반영됩니다.

**8. 얼마나 자주 돌리면 되나요?**
주 1회면 충분하고, 새 도구를 설치했거나 설정을 바꿨을 때 한 번 더 돌리는 것을 권합니다. 상주 프로그램이 아니라서 돌릴 때만 동작합니다.

**9. 관리자(sudo) 권한이 필요한가요?**
아니요. 일반 사용자 권한으로 읽을 수 있는 범위만 점검합니다. 그래서 일부 시스템 수준 항목은 점검 범위 밖입니다(정직 한계).

**10. 어떤 걸 못 잡나요?**
이미 침해된 기기의 악성 흔적, 공유기/네트워크 바깥 경로, 제로데이, 알려진 패턴 밖의 비밀. 한계는 리포트 각 카드의 "못 하는 것"에 전부 적어 두었습니다.

**11. Windows/Linux에서 되나요?**
동작은 하지만 **전수 검증 전(실험적)** 입니다. macOS가 현재 정식 지원입니다.

**12. 피드백을 보내면 뭐가 좋아지나요?**
피드백이 곧 버전업입니다 — 이슈를 매일 수집해 백로그로 모으고, 개선→릴리스→CHANGELOG 공개 사이클로 돌립니다. 보낸 내용이 어디 반영됐는지 CHANGELOG에서 확인할 수 있습니다.
